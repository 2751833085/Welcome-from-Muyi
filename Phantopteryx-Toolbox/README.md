# Phantopteryx Toolbox (prototype)

The old community-tool prototype, preserved as a compact demo inside [Welcome from Muyi](../README.md). It uses its own dark, monospace look instead of the hand-drawn portfolio style.

[Open the live prototype](https://2751833085.github.io/Muyi-s-Portfolio/Phantopteryx-Toolbox/toolbox.html)

The original research version combined image editing, divination and optional AI services. This cleaned version keeps the public-facing navigation and two small demos. The full, rebuilt project lives elsewhere:

- [Live final project](https://phantopteryx-toolbox.web.app/)
- [Source repository](https://github.com/2751833085/Phantopteryx-Toolbox-by-Oneiron)

## Pages

| File | Purpose |
| --- | --- |
| [`toolbox.html`](toolbox.html) | Toolbox home with links to the demos |
| [`apps/image-editor/index.html`](apps/image-editor/index.html) | Image editor demo: brightness, contrast, saturation |
| [`apps/divination/divination.html`](apps/divination/divination.html) | Divination demo: draw a compact message |
| [`index.html`](index.html) | Launcher that plays the loader, then opens the toolbox |
| [`editor.html`](editor.html) | Launcher that plays the loader, then opens the image editor |

Both demos run entirely in the browser. Styles are inlined in each page, so the folder has no stylesheet of its own.
